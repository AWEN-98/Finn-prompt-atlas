# F·BASE 视觉反推浮窗

## 0.29.0 顶栏与队列减负

任务队列取消历史任务开关，新任务和已完成记录在同一队列中直接展示。顶栏仅保留任务、词库和运行设置，接口配置移入运行设置抽屉，后台连接状态移到当前任务底部。彩色九轴条和彩环改为单色九节点刻度，上传空状态同步使用克制的单色品牌标记。

## 0.28.9 首屏任务流优化

空状态任务卡改为内容自适应布局，收敛多层卡片与重复上传入口。上传图片成为主入口，网页点选和粘贴图片降为辅助操作。等待素材时隐藏重试按钮，失败任务才显示重试。主操作在缺少素材时明确提示先选择图片。顶部栏、文字对比度与圆角层级同步调整。

## 0.18.3 并发阶段与结果交付

- 多任务继续按运行设置并发执行，每张任务卡实时显示读取素材、证据建模、Agent 审校、中文整理、写入词库和生成图片。
- 反推与入库完成后立即展开提示词、色卡和画面解构，生图请求继续在该任务卡内等待，不再压住已经完成的反推结果。
- 生图阶段单独显示“生成图片”，解决任务已经进入生图却仍显示“正在反推”的误判。
- 视觉模型请求会使用独立的轻量分析副本，最长边限制为 1600 像素；原图存库、历史记录和对比查看仍保留原始素材。
- 二阶段标准审校的冗余输出上限已收紧，降低多任务同时运行时的响应等待。
- 多窗口执行器增加存活检测；插件重载或执行窗口关闭后遗留的运行卡会恢复为可重新开始，避免永久卡在运行中。

## 0.18.2 独立并发任务卡

- 每次发送、粘贴和上传都会创建一张新的独立任务卡，并自动切换到新卡供用户选择运行方式。
- 单张“开始反推”和“反推并生成”只启动当前卡，其他待办保持静止；“批量运行”才会显式启动全部待办。
- 多张卡可按运行设置的并发数同时工作，每张卡独立保存原图、补充要求、API 快照、运行状态、拆解结果和生图结果。
- 切换任务不再改写运行状态，后台任务完成时只更新所属卡；用户正在查看其他卡时，主展示区不会被抢占。
- 任务卡增加单独开始按钮，运行中与排队中的卡禁止清图或删除，避免产生悬空任务。

## 0.18.1 旋转画布与动作接触保真

- 真实摄影始终判断画面旋转状态，区分最终画布方向和场景内容方向。
- 正交旋转与侧置观看画面新增重力参照，锁定现实地面映射到画布的边缘。
- 桥式、后弯、倒立和复杂支撑动作新增动作类别与支撑接触图。
- 每只可见手脚分别记录承重、轻触、抬起、悬空、遮挡或出框，阻止四点支撑漂移成三点支撑。
- 主体占位同时记录包围区域、主要负空间方向和面积关系。

## 0.18.0 跨类型复现保真

- 手机随拍、低照度、直闪和压缩画面新增采集成像签名、清晰度地图与曝光分布。
- 悬挂、绳索和高难动作新增主体占位、空间骨架、透视强度与支撑受力合同。
- 低机位近景新增面部几何、面部成熟度与服装张力分布，限制透视和褶皱扩张。
- 三维游戏角色新增数字渲染媒介、渲染签名、曝光分布与非对称装备结构，锁定数字角色质感。
- 人物保真护栏会按自拍、复杂动作和普通人像分别选择透视规则。

## 0.17.2 实物模型质感保真

- 反推先识别现实物体摄影、活体摄影、插画和数字渲染，再分析角色与题材，避免模型外形被编译成活体生物。
- 桌面承载、接触投影、纹理尺度、球形或转轴关节、装配缝、分件边界和喷涂表面会共同触发产品静物路径。
- 实体产品新增“实物媒介、尺度线索、制造与装配证据”；存在可见关节时再增加“可动关节系统”。
- 可动模型提示词优先锁定小比例桌面产品摄影、塑料或树脂制造、关节分件和平滑喷涂，再写角色造型、姿态、场景和灯光。
- 两阶段审校会拦截实体可动模型被改写成连续有机生物、无关节整体雕塑、数字概念渲染或全身粗糙骨质。

## 0.17.1 单图单任务

- 每次右键“发送到 F·BASE”或网页点选都会生成唯一捕获编号，并创建独立待处理任务。
- 同一图片再次发送也会创建新任务；同一发送事件在多窗口同步时仍只保留一份。
- 原始素材模块只显示当前任务的一张主图，其他图片只在任务队列中显示，不再并排挤进当前素材区。
- 浮窗首次打开时收到的图片会在共享工作台恢复后正式入队，多窗口同步会恢复当前任务对应的素材。

## 0.17.0 材质与形体保真

- 雕塑、器物、概念生物和混合视觉新增“轮廓与拓扑、材质本体、表面状态、损伤分布”四栏。
- 反推先锁定实体材质和局部损伤范围，再写题材语义，降低骨瓷、象牙、甲壳等质感被泛化成腐朽骨骼的概率。
- 单侧薄壳、肩甲、披覆片、翼膜和完整翅翼按数量与连接拓扑区分，减少对称双角和巨大破翼漂移。
- 插件与词库后端共用同一套材质拓扑审校合同。

## 0.16.3 并发任务结果隔离

修复多任务同时运行时原图、生成图和拆解档案交叉显示的问题。生图函数现在接收任务上下文，并按任务 ID 与分析 ID 绑定画幅证据、提示词、原图、生成图、历史记录和作品库写入。后台任务完成后会一次性切换同一任务的整组结果；渲染层还会拦截分析 ID 不一致的旧生成图。

## 0.16.2 单次生成与并发恢复

移除自动返图校准开关。开始反推只生成并保存中文提示词，不调用生图模型；反推并生成和提示词卡中的生成按钮每个任务只生成一张。临时候选图、多轮审校和重复作品写入不再触发。并发任务数恢复为用户设置的 1 到 6 个，不再强制单任务运行。

## 0.16.1 纯文生提示词校准

运行设置中的“纯文生校准”恢复为严格的文字复现闭环。原图只进入视觉拆解和候选审校，生图 API 的请求体只包含中文提示词、模型、尺寸和质量参数。首次提示词会先补齐十维自足硬约束，候选图与原图比较后只修订误差最大的三项，最多校准两轮，最佳中文提示词回写当前反推结果和词库记录。所有存库提示词禁止使用“原图、参考图、如图、保持一致”等依赖外部图像的表达。

## 0.16.0 GPT Image 2 原图参考复现

运行设置中的“高保真复现”会把原图、中文提示词和十维硬约束一起提交给生图模型。GPT Image 2 原生图像接口会自动切换到 `images/edits` 并采用高质量输出；兼容模式继续支持多模态 Chat Completions。接口返回“模型不支持 Chat Completions”时会自动改用图像接口。每轮候选仍按构图、相机透视、面部几何、发型拓扑、身形比例、动作、服装、背景、光线和成像加权审校，最多修正两次。

## 0.15.0 人像十维锚点闭环

高相似度模式会在首次生图前从原图建立构图、相机透视、面部几何、发型拓扑、身形比例、动作、服装、背景几何、光线色彩和成像质感十个硬约束。候选审校采用前端加权分数，每轮只改误差最大的三项，并保留其余已经匹配的锚点。生图接口仍只接收中文文字提示词。

## 0.14.2 反推后直接生成修复

自动入库响应不再用空字段覆盖本地完整提示词。点击生成时会依次从当前结果、当前任务、对应历史记录和已显示的提示词卡恢复提示词，避免反推结果已经展示却提示尚未完成反推。

## 0.14.1 网页全屏图片查看器

结果图和原图的查看器已迁移到网页注入层，可覆盖整个浏览器网页视口。支持结果图、原图和对比三种视图，单图独立滚轮缩放、拖动平移、双击复位、工具栏缩放及 Esc 关闭。窄屏下对比视图自动改为上下布局。

## 0.14.0 纯文生高相似度闭环

运行设置新增“高相似度闭环”。开启后先按反推提示词生成候选图，再由视觉模型同时审校目标原图与候选图，按构图、面部、身形、姿态、服装、背景、光线和成像八个维度自动改写完整中文提示词并重新生图，最多额外生成两次，最终选择视觉审校评分最高的结果。生图接口全程只接收文字提示词。

## 0.13.9 队列完成态同步

多窗口共享工作区新增完成任务墓碑，已完成任务不会被其他窗口延迟写回的旧运行快照重新放入队列。运行中数量改为按实际任务状态统计，并发任务数大于一时也会准确显示。

## 0.13.8 独立图片预览

对比预览统一为 F·BASE 浅青瓷视觉。结果图和原图拥有各自独立的缩放与平移状态，支持点击选图、滚轮缩放、拖动平移、双击复位，以及顶部缩小、百分比复位和放大按钮。

## 0.13.7 人像身形保真

人物保真扩展到肩宽与头部比例、胸腰轮廓、躯干长度、上臂粗细、服装贴合与承托结构，以及自拍俯拍的近大远小和纵向缩短关系。AUTO 生图在历史恢复和重新生成时继续读取档案中的原图比例，并把最终画幅、人物占位和边缘裁切写入生图提示词。

## 0.13.6 运行控件统一

生图模型改为 F·BASE 自定义展开面板，支持长模型名省略、当前项高亮、默认标记和面板内滚动。并发任务数改为与运行设置一致的步进卡片，统一控件高度、圆角、边框、状态色与窄窗口布局。

## 0.13.5 人物保真与运行设置

运行设置新增“人物保真”开关。开启后，真实人像反推会强化脸型比例、眼裂与虹膜占比、鼻唇结构、眉眼妆容和自拍透视，并清理会压制原图幼态、大眼或短下巴特征的冲突约束。运行设置统一为卡片、分组按钮、说明文字和状态开关，并适配窄窗口排列。

## 0.13.4 手动执行

网页点选、右键发送和悬浮拾取只会把图片加入待处理队列。用户需要对当前图片点击“开始反推”或“反推并生成”。同一来源图片使用稳定任务 ID，多个 F·BASE 窗口收到同一次采集时不会生成多份任务。

## 0.13.3 对比预览

重做生成结果 Lightbox。宽窗口采用图片与解构双栏，窄窗口自动切换为图片在上、解构在下。统一深色解构表格、滚动条、顶部切换控件和图片留白，避免图片被固定侧栏挤成窄条。

## 0.13.2 密钥复用

共享档案从后端同步时继续使用末四位脱敏显示。插件会按档案 ID 在浏览器本机保留完整密钥，并在切换档案、刷新配置和获取模型时自动恢复。已有档案升级后输入并保存一次即可。

## 0.13.1 模型获取

API 设置中的“获取全部模型”会同时请求反推 API 与生图 API 的模型列表。生图模型拥有独立的搜索、系列分组和切换菜单，并随共享 API 档案保存。

## 0.13.0 反推方法融合

标准与精准模式默认启用两阶段视觉取证。第一阶段执行八类图像路由与字段拆解，第二阶段重新查看原图，结合通用图片反推和写真提示词方法完成证据纠错、字段覆盖审计、画幅锁定、中文提示词编译与同系列变体设计。简洁模式保留单次模型调用。

## 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启开发者模式。
3. 点击“加载已解压的扩展程序”。
4. 选择当前 `extension` 文件夹。

## 0.8.4 核心流程

1. 点击工具栏图标或网页右下角 F·BASE 悬浮球，打开网页内浮动窗口。
2. 在设置中创建共享 API 档案，填写 OpenAI 兼容 API 地址、Key 和支持图像输入的模型 ID。词库网页和插件使用同一套档案。
3. 使用图片悬停发送、网页点选、右键菜单、粘贴图片或上传图片，也可以只输入提示词。
4. 模型请求通过扩展后台直连用户配置的 API。共享档案保存在本机 D 盘数据库，配置接口仅允许本机网页和本机扩展访问。
5. 反推生成图像类型、深度拆解、完整中文提示词、同风格变体和本地确定性色卡。
6. 结果自动写入本机 F·BASE `/api/finn/import`，原图、拆解、提示词、变体和九轴词条同时保存。

## 悬浮球快捷设置

右键点击 F·BASE 悬浮球可以打开快捷控制层。这里可以直接点选、粘贴或上传图片，切换画幅比例、反推模型、生图模型和提示词精度，并控制变体提示词、图片检索按钮、色卡模式、默认参考色卡和动作参考模式。模式设置会进入下一次反推请求并跟随解构档案保存。

## 拆解工作台

深度拆解按成像、光色、镜头构图、人物动作、造型材质和场景版式分组。支持搜索、分类筛选、分组折叠、单词收藏、整行收藏、分组收藏、全部收藏、取消收藏、逐行复制和色卡复制。

## 收藏

- 点击拆解胶囊收藏单个词。
- 点击拆解行右侧星标收藏整条内容。
- 使用“全部收藏”批量保存所有拆解行。
- 完整提示词和变体提示词均有独立收藏按钮。

## 本机服务

点击“打开词库”时会检查 `http://127.0.0.1:3000`。服务离线时，扩展通过 `com.fbase.launcher` 本机启动器启动 D 盘后端，健康检查通过后再打开词库网页。

生图 API 地址、Key 和模型 ID 会跟随共享档案保存，当前版本不会调用生图接口。
